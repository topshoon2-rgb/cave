# 내 목소리 클론 만들기 (Mac 로컬 세션용)

이 문서는 **Mac에서 여는 로컬 Claude Code 세션**에 넘기는 작업 지시서입니다.
클라우드 세션은 Mac의 파일을 볼 수 없고 GPU도 없어서, 목소리 학습은 Mac에서 해야 합니다.

## 0. 이 문서 쓰는 법 (사람이 할 일)

1. Claude 데스크톱 앱에서 새 세션을 만들 때 **클라우드가 아니라 로컬(내 컴퓨터)**을 고르고,
   폴더는 `~/Downloads/voice-train`을 선택합니다.
   터미널을 쓴다면 다음과 같이 입력합니다.
   ```bash
   cd ~/Downloads/voice-train
   claude
   ```
2. 이 문서 전체를 복사해서 첫 메시지로 붙여넣습니다. 아니면 이 파일을 `voice-train` 폴더에
   넣고 아래 한 줄만 보내도 됩니다.
   ```
   voice-clone-local-setup.md 를 읽고 그대로 진행해 줘. 단계마다 결과를 보고하고, 설치나 다운로드 전에는 물어봐 줘.
   ```

---

## 1. 배경 (Claude가 알아야 할 것)

- 사용자는 한국어 **재테크·투자 유튜브 채널**을 준비하고 있습니다.
  채널 기획과 영상 자동화 코드는 GitHub `topshoon2-rgb/cave` 저장소에 있습니다(공개 저장소).
- 영상 내레이션을 사용자 본인 목소리로 만들기 위해 **GPT-SoVITS**(MIT 라이선스, 무료,
  한국어 지원)로 목소리 모델을 학습합니다. 유료 TTS(ElevenLabs 등)는 쓰지 않기로 했습니다.
- 학습 재료는 지금 폴더에 있습니다.
  - `wavs/` 사용자가 직접 녹음한 음성 파일
  - 각 음성 파일의 대사 텍스트 (파일 형식과 위치는 1단계에서 확인)
- 컴퓨터는 Mac입니다. 칩(Apple Silicon 또는 Intel)과 메모리는 아직 모르니 먼저 확인합니다.

## 2. 지켜야 할 규칙

- **음성 파일과 학습된 모델 파일은 절대 GitHub에 올리지 않습니다.** `cave`는 공개 저장소라
  누구나 내려받아 사용자 목소리를 복제할 수 있습니다. 녹음, 모델, 생성 음성은 Mac에만 둡니다.
- 원본 `wavs/`와 텍스트 파일은 **수정하지 않습니다.** 변환이나 정리가 필요하면 새 폴더에
  복사본을 만듭니다.
- 프로그램 설치(Homebrew, conda, pip)나 대용량 모델 다운로드 전에는 사용자에게
  무엇을 왜 설치하는지 한 줄로 말하고 확인을 받습니다.
- 단계마다 결과를 짧게 보고합니다. 사용자는 개발자가 아니니 쉬운 말로 설명합니다.

## 3. 작업 순서

### 1단계: 컴퓨터와 데이터 점검 (설치 없이)

1. Mac 사양 확인: 칩, 메모리, 남은 디스크 용량.
   ```bash
   sysctl -n machdep.cpu.brand_string; sysctl -n hw.memsize; sw_vers; df -h ~
   ```
   설치와 모델 다운로드에 넉넉히 20GB 이상 여유가 있는지 봅니다.
2. 데이터 점검 후 표로 보고합니다.
   - 음성 파일 개수, 형식(wav 등), 샘플레이트, 모노/스테레오
   - 파일별 길이와 **전체 길이**
   - 텍스트 파일 형식. GPT-SoVITS의 `.list` 형식인지, 파일마다 따로 된 `.txt`인지, 다른 형식인지
   - 음성과 텍스트 짝이 모두 맞는지 (텍스트 없는 음성, 음성 없는 텍스트)
   - 너무 짧거나(1초 미만) 너무 긴(20초 초과) 파일
   - 몇 개를 골라 들어 보고(또는 음량을 분석해서) 잡음, 음악, 무음 구간이 심한 파일
3. 판정: 이대로 학습해도 되는지, 보충 녹음이 필요한지 말해 줍니다. 전체 길이가 짧으면 몇 분을
   더 녹음하면 좋은지 제안합니다.

### 2단계: 학습용 목록 파일 만들기

GPT-SoVITS는 아래 형식의 `.list` 파일을 씁니다. 언어 코드는 한국어 `ko`입니다.
```
음성파일_절대경로|화자이름|ko|대사 텍스트
```
- 화자 이름은 `me`처럼 하나로 통일합니다.
- 텍스트는 **실제로 말한 그대로**여야 합니다. "3.5%"를 "삼 점 오 퍼센트"로 읽었다면 텍스트도
  읽은 대로 맞춥니다. 확실하지 않은 줄은 고치지 말고 목록으로 보여 주고 사용자에게 묻습니다.
- 결과는 `dataset/me.list`처럼 새 파일로 저장합니다.

### 3단계: GPT-SoVITS 설치 (사용자 확인 후)

공식 저장소를 씁니다. 이 문서는 2026-08-18 커밋 `48b1a01` 기준으로 작성했습니다.
```bash
brew install ffmpeg                       # 없으면
# conda가 없으면 Miniforge 설치를 제안
git clone https://github.com/RVC-Boss/GPT-SoVITS.git ~/GPT-SoVITS
cd ~/GPT-SoVITS
conda create -n GPTSoVits python=3.10 -y
conda activate GPTSoVits
bash install.sh --device CPU --source HF
```
- 공식 README에 따르면 Mac GPU(MPS)로 학습한 모델은 품질이 크게 떨어져서, **Mac에서는 CPU 학습**을
  권장합니다. 그래서 `--device CPU`가 기본입니다.
- CPU 학습이 너무 오래 걸리면(몇 시간 이상 예상) 사용자에게 알리고 다음 대안을 제안합니다.
  - 학습만 공식 Colab 노트북(`Colab-WebUI.ipynb`)의 무료 GPU에서 하고, 완성된 모델을 Mac으로 가져와
    음성 생성만 Mac에서 합니다.
  - 비공식 Mac 전용 포크(`vibe570/GPT-SoVITS-Apple-Silicon-MPS`)도 있지만 공식 프로젝트가 아니므로,
    쓰기 전에 사용자에게 위험을 설명하고 동의를 받습니다.
- 설치 명령은 바뀔 수 있으니 진행 전에 `README.md`의 macOS 항목을 다시 확인합니다.

### 4단계: 학습

```bash
cd ~/GPT-SoVITS && conda activate GPTSoVits
python webui.py
```
브라우저에서 학습 화면(기본 포트 9874)이 열립니다. `1-GPT-SoVITS-TTS` 탭에서 다음 순서로 진행합니다.
1. 데이터셋 포맷팅: 2단계의 `.list` 파일과 음성 폴더를 지정하고 전처리를 실행합니다.
2. 미세조정 학습: SoVITS 모델을 먼저 학습한 뒤 GPT 모델을 학습합니다. 처음에는 기본 설정으로 합니다.
3. 학습이 끝나면 만들어진 모델 파일 이름과 위치를 기록합니다.

화면 구성은 버전마다 조금씩 다를 수 있으니, 사용자에게 무엇을 누르면 되는지 화면 기준으로 안내합니다.
명령줄로 할 수 있는 단계는 명령줄로 진행해도 됩니다.

### 5단계: 품질 테스트

`1-GPT-SoVITS-TTS` → `1C-inference`(추론 화면, 기본 포트 9872)에서 학습한 모델을 고르고 다음을 정합니다.
- **참조 음성:** `wavs/`에서 또렷하고 평소 톤인 3~10초짜리 파일 하나와 그 대사 텍스트

아래 테스트 문장을 생성해서 `test-output/`에 저장하고, 사용자에게 들어 보라고 합니다.
```
월급이 들어오자마자 사라진다면, 오늘 영상이 도움이 될 거예요.
ISA, 연금저축, IRP 중에 하나만 고른다면 저는 이렇게 고르겠습니다.
연 3.5% 금리로 2,000만 원을 1년 동안 넣으면 이자는 얼마일까요?
S&P500 ETF를 국내 상장으로 살지, 미국 상장으로 살지 세금까지 비교해 볼게요.
이 영상은 투자 권유가 아니며, 투자 판단과 책임은 본인에게 있습니다.
```
숫자, 퍼센트, 영어 약어(ETF, ISA, IRP, S&P500)를 잘못 읽는지 확인합니다. 잘못 읽으면
"대본에서 숫자를 한글로 풀어 쓰기"처럼 대본 쪽에서 해결하는 규칙을 정리해 둡니다.

### 6단계: 자동화용 API로 띄우기

영상 자동화 코드가 대본을 넣으면 음성을 받아 갈 수 있게 API 서버로 실행합니다.
```bash
cd ~/GPT-SoVITS && conda activate GPTSoVits
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```
학습한 모델로 바꾸려면 `/set_gpt_weights`, `/set_sovits_weights`를 호출하거나 설정 파일을 수정합니다.
테스트 예:
```bash
curl -X POST http://127.0.0.1:9880/tts -H "Content-Type: application/json" -d '{
  "text": "월급이 들어오자마자 사라진다면, 오늘 영상이 도움이 될 거예요.",
  "text_lang": "ko",
  "ref_audio_path": "/참조음성/절대경로.wav",
  "prompt_text": "참조 음성의 대사",
  "prompt_lang": "ko",
  "text_split_method": "cut5",
  "media_type": "wav"
}' --output test-output/api-test.wav
```

### 7단계: 마무리 보고

`~/Downloads/voice-train/voice-model.md`에 아래 내용을 정리합니다. 이 파일에는 음성이 없으니
나중에 `cave` 저장소로 옮겨도 됩니다. 단, 사용자의 Mac 절대 경로는 `~/`로 바꿔 적습니다.
- 데이터 요약: 파일 수, 전체 길이, 제외한 파일과 이유
- 설치한 GPT-SoVITS 버전(커밋), 학습 방식(CPU/Colab), 걸린 시간
- 사용할 모델 파일 이름, 참조 음성 파일 이름과 대사
- API 실행 명령과 요청 예시
- 테스트에서 발견한 발음 문제와 대본 작성 규칙 (예: "퍼센트는 한글로 쓴다")
- 다시 학습한다면 보충할 녹음

## 4. 덤: 말투 파일(voice.md) 재료

녹음 텍스트는 사용자의 실제 말투이므로, `cave` 저장소의 `channel/voice.md`를 완성하는 재료가 됩니다.
텍스트 전체를 분석해서 다음을 `voice-model.md` 끝에 따로 정리해 주세요.
- 자주 쓰는 표현과 입버릇 5개 이상
- 평균 문장 길이, 존댓말 형태(해요체/합니다체)
- 대표 문장 10개 (그대로 인용)

이 부분은 공개 저장소에 들어갈 수 있으니, 개인 정보가 담긴 문장은 빼고 사용자에게 확인을 받습니다.

## 5. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `conda: command not found` | Miniforge를 설치하고 터미널을 다시 엽니다 |
| 설치 중 모델 다운로드 실패 | `--source HF-Mirror` 또는 `--source ModelScope`로 다시 실행합니다 |
| 학습이 너무 느림 | Colab에서 학습하고 Mac에서는 음성 생성만 합니다 (3단계 참고) |
| 목소리가 기계적이거나 떨림 | 잡음 있는 파일을 빼고, 참조 음성을 다른 파일로 바꿔 봅니다 |
| 한국어 발음이 어색함 | 텍스트가 실제 발화와 일치하는지 다시 점검하고, 학습 데이터를 보충합니다 |
| `wavs` 폴더 소리가 작거나 들쭉날쭉함 | 원본은 두고 복사본만 음량을 맞춘 뒤 학습합니다 |

## 6. 다음 연결 (클라우드 세션에서 할 일)

목소리 모델이 완성되면, `cave` 저장소의 영상 생성 파이프라인이 Mac의 `http://127.0.0.1:9880/tts`를
호출하도록 연결합니다. 그러려면 파이프라인을 Mac에서 실행해야 하므로, 그 단계도 로컬 세션에서 진행합니다.
