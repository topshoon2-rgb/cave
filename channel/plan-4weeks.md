# 첫 4주 업로드 계획

`/yt-plan`의 틀(메인 영상 1개, 가벼운 영상 1개, 메인에서 잘라낸 쇼츠 3개)로 짰습니다.

**가정:** 주 10시간 작업, 채널 분석 데이터 없음. 그래서 업로드 요일은 임시로 정했습니다.
실제 가능한 시간과 4주 뒤 분석 데이터(시청자가 많이 들어오는 요일)를 보고 다시 맞춥니다.

제목은 작업용 제목입니다. 확정 전에 `/yt-package`로 썸네일 글자와 함께 검사합니다.
제도 숫자(한도, 세율)는 제작하는 날 공식 출처로 확인하고 기준일을 화면에 넣습니다.

## 1주차: 채널의 약속 보여주기

| 요일 | 형식 | 작업용 제목 | 이 영상이 약속하는 한 문장 | 이미 있는 것 |
|---|---|---|---|---|
| 화 | 메인 (10~12분) | 월급 300 직장인이라면? AI랑 같이 짠 첫 투자 순서 | 투자를 처음 시작하는 직장인이 무엇부터 어떤 순서로 하면 되는지 알 수 있다 | 없음 (`strategy.md`의 기둥 ①②가 뼈대) |
| 목 | 가벼운 영상 (3~5분) | 이 채널이 종목 추천을 안 하는 이유 | 이 채널에서 무엇을 얻고 무엇은 얻지 못하는지 알 수 있다 | `strategy.md`의 콘셉트 |
| 금~일 | 쇼츠 ×3 | 메인 영상에서 잘라냄 | 각 쇼츠마다 질문 하나 | `/yt-shorts`로 후보 추출 |

"월급 300"은 예시로 든 가정입니다. 채널 주인의 실제 월급인 것처럼 말하지 않습니다.

## 2주차: 검색 유입 만들기 (기둥 ① 제도·절세)

| 요일 | 형식 | 작업용 제목 | 약속하는 한 문장 | 이미 있는 것 |
|---|---|---|---|---|
| 화 | 메인 | ISA vs 연금저축 vs IRP, 하나만 고른다면? | 내 상황(나이, 목표, 돈이 묶여도 되는 기간)에 맞는 절세 계좌를 고를 수 있다 | 1주차 영상의 "투자 순서" 중 한 단계 |
| 목 | 가벼운 영상 | 1주차 댓글 질문 답변 | 1주차에 가장 많이 나온 질문에 답한다 | 1주차 댓글 (`/yt-comment`) |
| 금~일 | 쇼츠 ×3 | 메인에서 잘라냄 | 계좌 하나씩, 핵심 하나씩 | |

## 3주차: 숫자로 비교하기 (기둥 ② 상품 비교)

| 요일 | 형식 | 작업용 제목 | 약속하는 한 문장 | 이미 있는 것 |
|---|---|---|---|---|
| 화 | 메인 | S&P500 ETF, 국내 상장 vs 미국 상장: 세금까지 AI로 계산해 봤다 | 같은 지수를 어느 시장에서 사느냐에 따라 세금과 비용이 어떻게 달라지는지 안다 | 2주차 절세 계좌 내용 (계좌 안에서 사는 경우와 연결) |
| 목 | 가벼운 영상 | 이 계산에 쓴 AI 프롬프트 그대로 공개 | 시청자가 자기 금액으로 직접 계산해 볼 수 있다 | 메인 영상 제작 때 쓴 프롬프트 |
| 금~일 | 쇼츠 ×3 | 메인에서 잘라냄 | | |

## 4주차: 차별점 보여주기 (기둥 ③ AI로 분석해봤다)

| 요일 | 형식 | 작업용 제목 | 약속하는 한 문장 | 이미 있는 것 |
|---|---|---|---|---|
| 화 | 메인 | 실적 발표, AI로 10분 만에 읽는 법 | 기업 실적 발표에서 무엇을 봐야 하는지, AI에게 무엇을 물어야 하는지 안다 | 3주차의 "프롬프트 공개" 반응 |
| 목 | 가벼운 영상 | 4주 운영 결과 공개: 조회수, 유지율, 배운 것 | 채널을 처음 키우는 과정을 솔직하게 보여 준다 | 4주치 YouTube 스튜디오 데이터 |
| 금~일 | 쇼츠 ×3 | 메인에서 잘라냄 | | |

4주차 메인에서 실제 기업을 예시로 쓸 때는 "읽는 법"만 다루고, 그 기업 주식을 사라·팔라는 결론은 내지 않습니다.

## 시간 계산 (주당)

| 작업 | 시간 |
|---|---|
| 메인 영상: 자료 확인, 대본, 녹음, 편집 | 약 6시간 (영상 생성 AI가 완성되면 줄어듦) |
| 가벼운 영상 | 약 2시간 |
| 쇼츠 3개 | 약 1시간 |
| 업로드 준비와 댓글 | 약 1시간 |
| **합계** | **약 10시간** |

**주가 무너지면 빼는 순서:** 쇼츠 3개 → 2개, 그다음 가벼운 영상. 메인 영상은 지킵니다.
